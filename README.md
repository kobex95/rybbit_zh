## ✨ 主要功能

- 所有关键网页分析指标，包括会话、独立用户、页面浏览量、跳出率、会话时长
- 会话回放
- 无Cookie且注重隐私
- 可定制的目标、留存率、用户旅程和漏斗仪表板
- 跨15多个维度的高级筛选
- 支持JSON属性的自定义事件
- 三级位置追踪（国家->地区->城市）+ 高级地图可视化
- 实时仪表板
- 支持组织和无限数量的网站
